# GHOST OPEN WORLD

A mobile-first third-person 3D urban exploration prototype for Android, targeting the Poco X7 Pro.

## First playable milestone
- A small, original, fictional city block with damaged buildings and atmospheric lighting.
- An original masked operator character (not copied from Call of Duty or another commercial game).
- Third-person camera and basic walking/running.
- Touch-friendly on-screen movement and camera controls, with gamepad support planned.
- A lightweight Godot 4 project structure, optimized before expanding the world.

## Development plan
1. Establish a bootable Godot project and a small test scene.
2. Add a placeholder player and third-person movement/camera.
3. Add mobile touch controls and performance settings.
4. Replace placeholders with properly licensed original assets.
5. Test on the target Android device before expanding the map.

## Important limits
GitHub stores the source files; it does not run Godot or automatically produce an Android APK. A Godot editor/export setup and device testing are still required. No commercial game assets, characters, logos, music, or levels are included.
